# 河北医科大学题库刷题

**在线刷题：** https://lancistar.github.io/hebmu-question-bank/
**仓库地址：** https://github.com/lanciSTar/hebmu-question-bank

在线刷题 + 题库下载，纯静态页面，不依赖自建服务器。

- **在线刷题**：打开 Pages 首页，右下角切换题库
- **题库下载**：`docs/download.html`，按课程拆分，可单独下 JSON
- **可选后端**：接 Supabase 后有讨论区、全校正确率、跨设备进度；不接就是纯本地

## APK（安卓）

`河北医科大学题库刷题-v3.8.0-debug.apk`，debug 签名，可以直接安装。

- 首页「**离线题库（不用登录）**」：内置题库，点开就刷，不联网、不登录
- 首页「**开始使用（登录学校题库）**」：原在线模式，登录后实时拉学校题库

内置题库在 `assets/banks/`，每门一个 JS 文件，按需加载。

## 账号

- 登录/注册要填图形验证码（图片上的 4 位字符，点图片可换一张）。
- 用学号注册（邮箱是内部用的假地址，不用真的），昵称自动生成「冀医00001」这种，按注册顺序。
- 登录后才能发评论、看全校正确率、跨设备同步进度；不登录也能刷题。
- **忘记密码**：登录弹窗里点「忘记密码？」→ 填学号「申请验证码」→ 找管理员要 6 位验证码（QQ 群 1047914312）→ 填验证码和新密码重置。
- 管理员看验证码：Supabase 后台 → Table Editor → password_resets 表。

## 功能

- 章节 / 题型 / 收藏 / 错题 多条件筛选
- 单选、多选、判断、填空（`{{ANS}}` 占位）、主观题自评
- 逐题解析（题库自带；`{{OPT:n}}` 可引用选项）
- 背题模式（答案和解析直接展开）
- 连对次数筛选、题号范围、答题卡分页、本轮统计
- 进度导出 / 导入（换设备用）

## 目录

```
docs/               GitHub Pages 根目录
  index.html        刷题页
  download.html     题库下载页
  web-boot.js       启动器：读 data/index.json → 加载题库 → 起刷题界面
  web-supabase.js   Supabase 适配层（可选）
  config.js         Supabase 配置（留空 = 纯本地）
  data/             题库：index.json + 每门课一个 JSON
tools/              构建/抓取脚本
```


必须用 http 打开，`file://` 下 fetch 会被浏览器拦。

## 题库格式

`data/<id>.json`：

```json
{
  "id": "160",
  "name": "外科学",
  "chapters": [{ "name": "外科总论", "n": 649 }],
  "groups": { "A1型题": 1200 },
  "questions": [
    {
      "id": "160-5902",
      "ch": "外科总论",
      "t": "论述题",
      "atid": "6",
      "q": "题干",
      "a": "标准答案",
      "o": ["A. 选项一", "B. 选项二"],
      "ex": "解析",
      "blank": ["空1", "空2"]
    }
  ]
}
```

- `atid`：`0` 单选 / `1` 多选 / `6` 主观或填空
- `blank`：填空题答案数组，题干里用 `{{ANS}}` 占位

## 部署（GitHub Pages）

Settings → Pages → Source 选 `Deploy from a branch` → 分支选 `main`，目录选 `/docs`。
